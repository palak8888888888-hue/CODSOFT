# Task 2 – Credit Card Fraud Detection

**Objective:** Build a model to detect fraudulent credit card transactions.

**Dataset:** Contains features of credit card transactions with labels `is_fraud`.

**Approach:**
- Data preprocessing
- Feature selection
- Model training using:
  - Logistic Regression
  - Decision Trees
  - Random Forests
- Model evaluation using Accuracy, Precision, Recall, F1-score

**Results:** Achieved high accuracy in detecting fraudulent transactions.
